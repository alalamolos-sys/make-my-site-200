# Certif Auto — redesign clair

Landing page TanStack Start / React / TypeScript repensée pour une expérience plus claire et professionnelle.

## Lancer le projet

```bash
npm install
npm run dev
```

ou avec Bun :

```bash
bun install
bun run dev
```

## Fichiers principaux

- `src/routes/index.tsx` : contenu et structure de la landing page
- `src/styles.css` : direction artistique claire et responsive
- `public/favicon.png` : logo fourni

## À personnaliser avant mise en ligne

- Remplacer `contact@certif-auto.fr` par votre adresse réelle.
- Relier les boutons de connexion et les mentions légales.
- Vérifier les promesses commerciales chiffrées avant publication.
